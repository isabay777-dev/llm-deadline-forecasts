# Prospective local policy experiment

This follow-up uses live generations and interventions. It addresses an arrival-to-delivery service question with the already fitted direct predictor. The original frozen forecast study estimates a different outcome conditional on an active prefix and remains a separate experiment.

## Assignments and traffic

Use the previously verified Apple M5 Metal server, the same GGUF, sampling parameters, two slots, and 1,024-token maximum. Use twelve disjoint blocks of twelve held-out prompt families. Remove every family in the source, development and primary confirmation assignments from the common registry before sampling. Order the remaining families by SHA-256 of a fixed experiment label and family ID. Each scheduled job has the same tokens, seed and arrival time in all three arms. Each arm gets a new process and the same fixed warmup outside the evaluation window.

Use one foreground slot with FIFO dispatch and an unbounded waiting list. Schedule three jobs at 0.00, 0.12 and 0.32 s from the start of each of four bursts at 0, 4, 8 and 12 s. Send one EOS-disabled background request of at most 1,024 tokens on the second slot during each of [0,1.5), [4.5,6), [9,10.5), and [12,13.5) seconds. Disconnect that request at the end of its window if still active. Keep its actual lifetime and overlap. The foreground queue drains after the final burst. The three policies use all six within-block orders twice, assigned to blocks by a frozen shuffle. The buffer is modeled by the experiment's local dispatcher. Traffic is synthetic, open-loop, and identical within each block.

## Policies fixed before the first scientific arm

All arms invoke the same observer and forecast path on the first 32 native sampled tokens of a foreground request still active when observed. Use exactly that prefix and a fixed speed multiplier equal to the median of the three prior development-episode multipliers at historical budget five. Convert the remaining client budget into a probability with the saved direct model. The original target is measured from token 32. A real controller can observe the prefix later. Computing its input using the budget still available at the controller decision is a deployment approximation. Record callback and actuation delay and later tokens generated in the meantime. Cases that naturally finish before actuation retain their observed delivery outcome. No policy uses future requests to make a decision.

FIFO completes the current job. Expiry abandons it only if another job is already waiting and its one-second arrival-to-delivery deadline has expired when evaluated at the landmark. Forecast applies the same expiry rule and also abandons a still-feasible job if it has backlog and the predicted completion probability is below 0.25. The threshold is an operating point fixed before collection. It expresses no universal utility tradeoff. No continuous cancellation after the single decision. No dispatch-time rejection. The server actually stops receiving demand from the cancelled client and the dispatcher reuses the slot. Log disconnect, effective slot release, any native token overrun, and the request's terminal status. For an early EOS, absent actionable prefix, or no backlog, let the request finish. Set probability to zero for an already exhausted budget. For positive budgets the frozen direct predictor interpolates from its original raw (0,0) anchor before calibration; there is no separately fitted short-time endpoint. The fixed development speed multiplier is 1.3185974282888275. Verify the positive upper query range against the trained grid.

## Outcomes and inference

The unit of inference is the paired block. The primary contrast is forecast minus expiry in the number of timely naturally completed responses per fixed 14 s arrival window. A success requires the client to receive the final SSE completion frame carrying a natural stop reason by its scheduled arrival plus 1.0 s. The time of an earlier partial frame carrying an EOS token, when exposed, supplies a sensitivity endpoint. All twelve offered jobs form the denominator. A cancellation, limit stop, or late natural completion is a miss. The 14 s observation window contains the final deadline at 13.32 s. Also report per-offer timely fraction, absolute counts, paired differences in counts, actual wall time through drain, delivered natural completions, aborts, late decisions and active background share. Rates for the fixed windows do not estimate saturated production throughput. Forecast minus FIFO and expiry minus FIFO are secondary comparisons. Report the sample-mean paired difference and a two-sided 95% Student interval across 12 blocks (11 degrees of freedom). Report individual blocks including zeros. Claim a directional goodput gain over expiry only if the primary lower bound exceeds zero. A confidence interval overlapping zero leaves that claim unresolved. Twelve blocks are a fixed local replication budget without an asserted power guarantee.

## Integrity and recovery

Freeze the protocol, traffic manifest, model, speed adjustment, binary identity and collection code in a hash index before scientific collection. Isolated engineering smoke runs use other prompts and do not enter any endpoint. Do not inspect emerging treatment results to stop, resize, change the rule or choose the endpoint. Keep started attempts. On technical failure stop that collection, record the reason and retain its logs. Repeat a full block with its same assignments, arm order and traffic. If collection code must change after scientific runs begin, version the amendment and restart the series with fresh, unexposed families. Use the first valid complete block for each assignment. Validator checks assignment identities, physical device offload, response and request accounting, policy decisions and client timings. Release decisions and scope limits regardless of sign. No experiments on remote services.
