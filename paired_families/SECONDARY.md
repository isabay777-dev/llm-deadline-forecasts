# Speed-scaled calibration-frequency control

This secondary analysis was specified during the new OLMo source collection and before development or confirmation outcomes were scored for either new model. The two primary forecasts and their decision rules remain those of the paired-family protocol. The control asks whether a recent speed correction alone can forecast deadline attainment, without any request-specific prefix features beyond landmark eligibility. This extends the corresponding exploratory SmolLM2 check.

For each active idle source calibration run i, record the nanoseconds from token 32 to its natural end, using positive infinity if it is still active at the horizon. For episode e obtain the frozen direct method's recent-to-source step-duration ratio s_e using the five preceding history cases. For deadline d the forecast is the fraction of eligible calibration runs whose natural end time multiplied by s_e is at most d. Use the same forecast for every active test request in an episode. Use the model's own three calibration deadlines. No parameters are tuned on target data.

For each model, compare the mean three-deadline Brier of this control with the frozen direct and hazard forecasts on the same eligible loaded requests for which that method issued all three probabilities. Report the number of such requests and paired 95% episode-clustered descriptive intervals for control minus each method. Report the full-cohort control score separately. No success decision follows from these secondary contrasts. Separate the historical post hoc calculations from the two new-model calculations. For the existing SmolLM2 and Qwen studies use the original grid, source calibration and frozen scale; the historical data were already analyzed when this specific cross-family report was conceived.
